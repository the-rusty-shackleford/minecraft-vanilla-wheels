# Vanilla Wheels 1.9.0

Adds connected Rolling Garage Door panels. Flat rectangular doors up to 16 × 16 open when powered and close when power is removed, pausing for players, mobs and vehicles. Includes animated slats, tracks and a top roll. Eight steel ingots around redstone craft eight panels. Existing vehicle protocol 5 and vehicle profiles remain compatible.

Minecraft 1.21.1 · NeoForge 21.1.248 · Java 21. Install on both client and server.

Clean release validation: 92 JUnit tests, 57 real-server GameTests and the complete muted NVIDIA RTX 4070 / Iris / Complementary client walkthrough passed.

Rusty explicitly authorized publication and deployment of all three mods on
September 20, 2026, requesting a two-minute server warning. This supersedes the
earlier release holds. The clean jar is byte-identical to the reviewed candidate.
