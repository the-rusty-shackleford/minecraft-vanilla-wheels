# D-0011 — Shared contacts enter the existing driving model

The approved collision scope adds mass/speed-based planar momentum exchange, tangent
preservation and restrained wall rebound through the JDK-only Impact and Drive values.
D-0002/D-0007/D-0008's movement authority, collision replay and terrain pose remain.
The server calculates vehicle contacts once per held contact and sends a bounded
velocity to the controlling client, which applies it to Drive. No positional correction
payload or movement-validation bypass is introduced. Network protocol 4 rejects old peers.

An owner move already contains collision-clipped distance. Use its finite, bounded
reported approach speed for impact energy, retaining the actual move's direction.
A real-driver course reproduced insufficient parked-vehicle movement when clipped
movement alone supplied the impulse; the same regression is covered for glass.

Fragile destruction requires a driver with build permission, sufficient speed/energy,
a tagged block, a loaded chunk and an unobstructed path. Spawn protection and cancellable
NeoForge BreakEvent apply. Block entities and unbreakable blocks are excluded. Limit each
vehicle to 128 candidate checks/eight breaks per tick and deduplicate visited positions,
including denied breaks. Survival gets vanilla drops; creative gets none. Connected tow
trains and their passengers are excluded from impacts. No vehicle durability system is
added. A common config switch and datapack tag control fragile destruction.

Validation combines partitioned pure tests, real headless server tests and the owner
client's glass/stone/parked-vehicle course. Independent multiplayer synchronization and
historical live Pickup correction reproduction remain explicit group-test gates.
Release remains held; existing version numbers are not a publication receipt.
