# D-0017 — Normal garage panel placement

Rusty reinstated the adjacent-panel placement report and requested a small fix
and immediate release with focused verification. They then explicitly said the
instruction message could be removed entirely because the behavior is intuitive.
This supersedes the interaction-message requirement of D-0015 and D-0016.

Remove the block's consuming click handler. Minecraft's normal item-use path can
then place held blocks against the panel without crouching. Redstone remains the
only opener. Rectangle formation, four-direction facing and existing saves do
not change. No additional special-case held-item routing is needed.

Reuse the existing four-facing construction/redstone GameTest with ordinary edge
clicks instead of crouching. A selectable test namespace runs only this regression;
the default suite still includes it. No client or shader rerun is required for
this interaction-only patch, as explicitly requested by Rusty.
